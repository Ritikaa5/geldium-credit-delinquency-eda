# Geldium Delinquency Risk – EDA

## Objective
Analyze customer credit data to identify early risk indicators for payment delinquency.

## Dataset
- Credit card customer data
- Includes income, credit utilization, payment behavior

## Steps Performed
- Data quality checks
- Missing value handling
- Risk factor identification
- Correlation analysis

## Key Insights
- High credit utilization strongly correlates with delinquency
- Days past due is the strongest predictor
- Low income segments show higher risk

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
